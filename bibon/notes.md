# CHECKS BEFORE DEPLOYMENT

- Authorization ( Users can access only their own data )
- validate and sanitized all users inputs
- configured cors policy
- rate limiting on all API end-points
- password reset link expires
- catch unexpected errors on FE
- indexing setup on DB ( most commonly queries fields )
- logging ( debug stuffs on PROD )
- alerts ( immediately notify when something brakes )
- rollback when deployment goes wrong
